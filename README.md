## Quick Start (Windows / Linux / macOS)

```sh
# Clone & enter repository (all platforms)
git clone https://github.com/awesome-os/just-js-docs.git && cd just-js-docs
```

## Quick Install & Run (Windows / Linux / macOS)

```sh
# Install / hydrate from v11 CAS via holo-pm
holo-pm install repository://github.com/awesome-os/just-js-docs@main

# Or project & run directly via holo-project (0-byte hardlink)
holo-project "project://cpp/just-js-docs?from=repository://github.com/awesome-os/just-js-docs@main"
```
